Verificar por ti - sem depender de nós

Tudo o que é preciso é público. Um auditor independente não precisa de acesso nenhum da nossa parte:

  1. O código que corre é o publicado. Em /verificar a impressão (SHA-384) do tool.js servido é comparada com a publicada em versions.json, que aponta para a tag exata no GitHub.
  2. Reproduz do zero. Clona a tag desta versão em github.com/nobodykr/efatura-helper, corre node make-versions.mjs (recalcula a impressão) e node make-audit.mjs (recria esta tabela) - têm de dar o mesmo.
  3. Corre os testes. npm install && npm test corre as verificações de correção (incluindo test-deducoes-sync.js, que garante que a página, o código e os valores verificados concordam).
  4. Segue cada linha à lei. Cada linha da tabela liga ao artigo no Diário da República. Confirma lá o valor - não confies no nosso resumo.
